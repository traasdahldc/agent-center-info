Agent Center Personal

Privacy policy

Last updated November 15, 2026

Purpose and Google data

This application is for its owner's private use. Calendar setup accesses calendar identifiers and names so the owner can select calendars. Read-only event permission supports calendar questions initiated by the owner. Setup does not fetch appointments. The calendar tool reads only explicitly selected calendars within a requested date range of at most 31 days. It cannot create, edit or delete events.

Storage and control

Google authorization tokens and selected calendar identifiers are stored encrypted on the owner's Windows computer. These credentials and private calendar selections are excluded from the source repository and this informational website. The original calendar data remains in Google Calendar.

The owner can revoke authorization through Google Account third-party connections. Revocation prevents further authorized Google access but does not delete previously saved copies. Local connection files and any retained chat or backup copies must be removed separately.

AI processing and separation

Agent Center uses configured external AI providers for eligible requests. Calendar results are screened locally before ordinary AI processing. Eligible non-patient information may be sent to the owner-configured OpenAI or Anthropic services to answer the request. Detected patient information is withheld from ordinary providers and routed only to the separate Azure patient-processing path; a failed screening check blocks release. Automated screening can make mistakes and is not a guarantee that every sensitive item is detected.

Work authorization and Personal authorization are kept separate. Personal data must not be provided to Work agents. Personal can use both scopes. Calendar results are not separately indexed or automatically saved as shared memories by this tool. Eligible ordinary replies and conversation context can be retained in encrypted chat storage on the owner's home computer and its encrypted OneDrive recovery backup. Protected context uses the transient patient path rather than ordinary chat or shared memory. External providers process information under their applicable account terms and retention settings.

Use limitations

Google data is not used for advertising, sold, or used to train generalized AI models by this application. Agent Center Personal's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website

These static pages contain no application login, calendar data, analytics scripts, or advertising. The hosting provider may process ordinary website-request logs under its own policies.

Contact

For connection support or a privacy request, use the support email displayed on the Google consent screen. This application is operated for its owner, not offered as a public service.
