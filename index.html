Agent Center Personal

Agent Center Personal is an owner's private assistant for organizing questions, projects, and connected information. This website describes the application; it does not provide access to the assistant or its connected accounts.

Google Calendar connection

The owner authorizes a separate Personal Google connection and explicitly selects calendars. The current setup requests read-only access to list calendars and read events. It does not request permission to create, edit, or delete events.

Calendar selection is implemented. The agent-facing event retrieval integration is still under development. Its intended purpose is to answer the owner's calendar questions using only selected calendars and the application's data-screening controls.

Work and Personal authorizations are separate. Work agents must not receive Personal calendar information.
